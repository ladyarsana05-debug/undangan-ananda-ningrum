# Undangan Pernikahan Ananda & Ningrum

Website undangan statis HTML/CSS/JavaScript.

## Struktur
- `index.html` — halaman utama
- `style.css` — desain
- `script.js` — interaksi, musik, countdown, RSVP, guestbook
- `images/` — foto
- `music/` — file musik

## Sebelum upload
1. Ganti foto placeholder di `images/` dengan foto Anda, menggunakan nama file yang sama.
2. Masukkan file musik Anda sebagai `music/pujaningsih.mp3`.
3. Edit nama orang tua, alamat, rekening/e-wallet, nomor WhatsApp, dan link Maps di `index.html` / `script.js`.
4. Buka `index.html` di browser untuk testing.

## Catatan RSVP & Guestbook
Versi ini bersifat statis. Guestbook menggunakan localStorage browser, sehingga belum menjadi database bersama. RSVP menghasilkan tautan WhatsApp. Untuk data tamu yang tersimpan terpusat, sambungkan ke Google Forms/Sheets atau backend.

## Upload ke GitHub Pages
Buat repository public, upload seluruh isi folder ini, lalu:
Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.

Jangan mengupload data sensitif yang tidak ingin dipublikasikan.
